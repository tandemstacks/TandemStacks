# TandemStacks — notas para trabajar en este proyecto

App de escritorio para Windows que junta todas las bibliotecas de juegos (Steam, Epic, GOG, EA, Xbox / Game Pass, Riot, Battle.net, Rockstar, Ubisoft, Amazon Games, itch.io) en una pantalla. Open source (MIT), gratis para la comunidad. Repo: https://github.com/tandemstacks/TandemStacks (cuenta GitHub `tandemstacks`, mail tandemstacks@gmail.com; hasta la 1.1.2 se llamaba SantiStacks en rullans/SantiStacks; hasta la 1.3.6, TasloStacks en taslostacks/TasloStacks. El 08/11/2026 pasó a TandemStacks, de la familia de Tandem IA y Tandem Socio Digital. La app muda sola las carpetas viejas y el instalador reemplaza la instalación vieja (mismo AppId); la 1.3.6 busca el instalador por el nombre viejo, así que la primera release de TandemStacks lleva también una copia llamada TasloStacks-Setup-<v>.exe). Idioma del código, comentarios, UI y commits: **español rioplatense**.

Nació el 01/11/2026 como versión "para repartir" de una app personal (Santisteam), que ya se borró: **TandemStacks es la única app y es un proyecto independiente** (no depende de ninguna otra carpeta). Acá todo se detecta solo en la PC de quien lo instale.

## Cómo está armado

- `TandemStacks.pyw`: punto de entrada → `tandemstacks.app.main()`.
- `tandemstacks/paths.py`: carpetas y config. Config en `%APPDATA%\TandemStacks\config.json`; portadas, caché y `biblioteca.html` en `%LOCALAPPDATA%\TandemStacks`. Nada se escribe junto al programa. `ASSETS` apunta a `assets/` (o a `sys._MEIPASS/assets` dentro del exe).
- `tandemstacks/detect.py`: detección de los 11 launchers (registro + rutas típicas), color, URI para abrirlos, página de descarga y nombres de sus procesos. La config puede pisar cualquier ruta (`launchers: {"Steam": {"exe": ...}}`).
- `tandemstacks/steam.py`: usuario (de `loginusers.vdf`), instalados (appmanifest de todas las bibliotecas), biblioteca completa (Web API `GetOwnedGames`, necesita clave del usuario; sin clave solo instalados), fichas (`appdetails` + SteamSpy, caché 30 días en `cache/steam/<appid>.json`), y `buscar_appid()` para juegos de otras tiendas (coincidencia ≥ 0.92 y misma primera palabra; caché en `cache/busquedas.json`).
- `tandemstacks/stores.py`: Epic (catálogo `catcache.bin` = biblioteca completa + manifiestos `.item` = instalados, sin DLC ni extras), EA (Programas instalados con editor Electronic Arts; lanza el exe de `DisplayIcon`), Xbox (GamingServices + `Get-AppxPackage` por PowerShell; lanza `shell:AppsFolder\...`), Riot (catálogo fijo de 5 gratis; instalado = carpeta del `product_settings.yaml`; lanza `RiotClientServices.exe --launch-product=X --launch-patchline=live`, que también instala), Battle.net (7 gratis fijos + pagos solo si están instalados, por registro `Blizzard Entertainment`; lanza `battlenet://<código>`, que solo abre la página del juego; WoW se separa en una tarjeta por versión instalada según las carpetas `_retail_`/`_classic_`/`_classic_era_`/`_anniversary_` (`WOW_VERSIONES`) y lanza con `Battle.net.exe --exec="launch WoW|WoWC"`; Era y Aniversario no tienen código conocido y abren la página), Rockstar (títulos por los `manifest_<código>_*.xml` que baja el launcher en `%LOCALAPPDATA%\Rockstar Games\Launcher` + las portadas de la cuenta en `uipackages\assets\packages\public\<id>.jpg.cache`, que se reconocen por id fijo con la tabla `ROCK_PORTADAS` (hoy GTA V, Max Payne 3 y RDR2; sumar ids a medida que aparezcan); sus `.dat` están cifrados), Ubisoft (instalados por claves `Uplay Install <id>`, lanza `uplay://launch/<id>/0`; no instalados por los íconos `data\<id>.ico` que baja Ubisoft Connect junto a `upc.exe`, reconocidos con la tabla fija `UBI_ICONOS` (12 juegos; no hay lista pública de íconos: se suman a mano cuando avisan), lanzan `uplay://`), GOG (biblioteca = `LibraryReleases` `gog_*` + `GamePieces` de `C:\ProgramData\GOG.com\Galaxy\storage\galaxy-2.0.db`, se filtran extras/goodies; instalados por `HKLM\...\WOW6432Node\GOG.com\Games`; juega con `GalaxyClient.exe /command=runGame`, instala con `goggalaxy://openGameView/gog_<id>`), Amazon Games (solo instalados: `GameInstallInfo.sqlite`; `Entitlements.sqlite` está cifrado con DPAPI y no se lee a propósito; lanza `amazon-games://play/<id>`), itch.io (`%APPDATA%\itch\dbutler.db`: `download_keys` = biblioteca, `caves` = instalados; lanza `itch://caves/<id>/launch`). Las bases SQLite se copian a la caché antes de leerlas (están en uso).
- `tandemstacks/fichas.py`: **cada ficha muestra datos de SU tienda** (pedido del dueño 01/11/2026; nada se completa con Steam, salvo una excepción pedida el 07/11/2026: si Epic no tiene descripción se muestra la de Steam, aclarada, en `descSteam`; `steam_hint` es solo para portadas). Se pide solo al abrir la ficha (`Api.ficha(ids)`), con caché en `cache/fichas/<idioma>/`. Steam: horas y última vez de `userdata/<id>/config/localconfig.vdf` (o `GetOwnedGames` si hay clave) en el escaneo; logros de `appcache/stats/UserGameStats*.bin` (KeyValues binario, local) y si no, `GetPlayerAchievements` (da 403 con perfil privado). Epic: `store-content-ipv4.ak.epicgames.com/api/<loc>/content/products/<slug del título>`, válido solo si su `namespace` = el del catálogo (≈60 % aciertan; si no, lo de `catcache.bin`, cuya descripción suele ser el título y se descarta). Xbox: `displaycatalog` lookup → ProductId → `products?bigIds=` (descripción, estudio, categorías, PEGI, puntuación de la Microsoft Store). EA/Rockstar/Ubisoft: nada extra; Riot/Battle.net: catálogo fijo. "Reseñas Steam" solo en tarjetas que incluyen Steam.
- `tandemstacks/covers.py`: **las portadas son links, no se descargan** (decisión del dueño 01/11/2026, para que la app no pese). Orden: incluida en `assets/covers/` (solo Riot y Battle.net, que no tienen links fijos; `file:///`) → link del catálogo de Epic → Steam: link exacto de `IStoreBrowseService/GetItems` (público, de a 100 appids; los juegos nuevos usan `<hash>/library_capsule.jpg`), y si todavía no se pidió, `library_600x900.jpg` por appid o `steam_hint` (sirve también para Rockstar/EA) → Xbox: póster de `displaycatalog.mp.microsoft.com` por PackageFamilyName (link guardado en `cache/portadas.json`). Si un link falla, la plantilla (`sinPortada`) prueba `header.jpg` de Steam y si no, nombre sobre color. El visor corre con `private_mode=False` y `storage_path=%LOCALAPPDATA%\TandemStacks\visor` para que su caché de imágenes persista. Al arrancar se borra la carpeta `covers` vieja de versiones anteriores.
- `tandemstacks/watch.py`: hilo de toda la sesión que mira cada 15 s (cada 5 s con un juego abierto) si hay un juego andando, se haya lanzado desde donde sea (Steam: `HKCU\Software\Valve\Steam\RunningAppID`; otros: un proceso dentro de la carpeta de un juego instalado, sin contar ayudantes como `crash_reporter`). Cuando deja de haber juegos, si duró 30 s o más, cierra **todos los launchers abiertos** (Steam con `steam.exe -shutdown`, el resto terminate/kill con psutil); si queda otro juego andando no toca nada. Nombres genéricos (`launcher.exe`, `agent.exe`, `butler.exe`) solo cuentan si la ruta es del launcher. Regla del dueño (07/11/2026): nada corriendo al pedo.
  - **Al abrir un juego** (10/11/2026, `cerrar_otros`): al minuto se cierran los launchers que ese juego no usa. Se respetan su tienda, los que pide por archivos de su carpeta (`NECESITA`: Ubisoft, EA, Rockstar) y los que arrancaron después del juego (los abrió él).
  - **Al cerrarlo** (`limpiar`): se borra la basura segura: volcados de errores del juego, `Saved\Crashes` y logs `-backup-` de Unreal, `Crashes` de Unity en %TEMP%, `.dmp` de Steam, y cachés web de launchers cerrados si pasan los 300 MB. Nunca partidas, configuraciones ni caché de sombreadores.
  - **Medidor:** `ahorro.json` junto a la config (launchers cerrados, memoria y disco liberados); se ve en Configuración. No mide FPS a propósito. El plan de energía "Alto rendimiento" se descartó: casi no cambia nada en escritorio y gasta batería en notebooks.
- **Nivel:** `watch.vigilar` suma el tiempo con algún juego abierto (cualquier tienda, con TandemStacks abierta) y `Nucleo.sumar_jugado` lo guarda en `%APPDATA%\TandemStacks\nivel.json`. Arranca de cero para todos, sin recompensas por ahora. Niveles del 1 al 100: horas para el nivel n = 2190 × ((n−1)/99)^1,5 (`NIV_HORAS`, `NIV_EXP` en la plantilla), o sea el 100 a las ~2190 h, casi 3 años jugando 2 h por día. Una medalla cada 5 niveles (bronce, plata, oro, platino y leyenda en el 100); tocando el nivel se ven todas (`verMedallas()`).
- **Descargas:** `steam.descargas()` lee `BytesDownloaded`/`BytesToDownload` de los appmanifest y la página muestra una barra arriba. Por ahora solo Steam.
- `tandemstacks/build.py`: inyecta `window.JUEGOS/DISCOS/TIENDAS/CONF/ESTADO/LOGO` en `assets/template.html` y escribe `biblioteca.html`. `publico()` filtra lo que ve la página (sin rutas ni comandos).
- `tandemstacks/app.py`: `Nucleo` (escaneo en 2 fases: rápida sin red → fichas/portadas en 4 hilos publicando cada 8 s; vigilancia cada 12 s de manifiestos/registro para reescanear si algo se instala o desinstala; aviso de versión nueva por `api.github.com/repos/<repo>/releases/latest`, como mucho 1 vez por hora; **al abrir, si hay versión nueva se actualiza sola sin preguntar**, pedido del dueño 07/11/2026) y `Api` (lo que llama la página: `datos`, `estado`, `config`, `guardar_config`, `reescanear`, `version_nueva`, `abrir_url`, `abrir_datos`, `accion`). Ventana pywebview (WebView2), título e `AppUserModelID` "TandemStacks", ícono vía pythonnet/WinForms.
- `assets/template.html`: toda la UI (CSS + JS sin frameworks). La página no se recarga: cada 4 s pide `estado()` y si cambió `version` pide `datos()` y re-renderiza manteniendo filtros. Primer arranque (`CONF.primer_arranque`) abre la Configuración con bienvenida. Juegos repetidos entre tiendas se agrupan por nombre normalizado en una tarjeta. Cada grupo (Instalados, No instalados, No comprados) tiene sus propios filtros: tiendas con su cantidad, orden y géneros (`FIL`, `filtrosGrupo()`); arriba ya no hay filtros ni interruptor Instalados (pedido del dueño, 07/11/2026). Logos de tiendas: SVG inline de Simple Icons (Xbox dibujado a mano).
- Estética (pedida por el dueño): industrial, naranja `#ff6a00` + blanco, sin bordes, sombras, radios 3–5 px, fuente Bahnschrift, títulos en mayúsculas con barra naranja. Logo: `assets/hacer-logo.py` → `logo.png` / `icon.ico` (cuadrado naranja con una S de bloques).

## No comprados (02/11/2026, publicado en la v1.3.4)

- Tercer grupo de la biblioteca, abajo de Instalados / No instalados: juegos de los **catálogos públicos de GOG, Steam y Xbox** que no tenés en ninguna tienda (mismo nombre normalizado = misma tarjeta, no se repite). Si está en varias tiendas, la tarjeta muestra sus logos y al tocarla se elige dónde abrirla.
- `scripts/catalogos.py` junta `catalog.gog.com/v1/catalog`, los 10.000 más jugados de Steam (SteamSpy `request=all`, 1 página por minuto) y PC Game Pass (`catalog.gamepass.com/sigls` + `displaycatalog`) → `docs/catalogo/todos.json` (`t`, `c`, `st: {GOG: [id, slug], Steam: appid, Xbox: id}`; ~14.500 juegos, 2,6 MB), publicado con la landing. Tarda ~12 min.
- Al abrir, la app rehace `biblioteca.html` si cambió la huella de la plantilla (`cache/plantilla.txt`): antes mostraba la pantalla de la versión anterior. `.github/workflows/catalogos.yml` lo rehace solo todos los días a las 06:00 UTC (también a mano desde Actions); si el catálogo nuevo sale con menos del 80 % de los juegos, no lo publica.
- **Ubisoft y EA** (07/11/2026): salen del mapa del sitio de cada tienda (`store.ubisoft.com/us/sitemap_0.xml`, `www.ea.com/sitemap-en-us.xml`); se lee cada página y quedan solo los juegos de PC (Ubisoft: `productTypeDetail` games, sin `adultgame`, con precio en US$; EA: título "Buy …" y que se juegue con la app de EA). Las ediciones de un mismo juego van en una tarjeta.
- **itch.io, Battle.net y Rockstar** (07/11/2026): itch.io sale de sus listados públicos en RSS (`top-sellers` y `top-rated`, solo Windows, con precio); Battle.net y Rockstar son listas fijas en `catalogos.py` (`BATTLENET`, `ROCKSTAR`) con su página de compra verificada. Tocar la tarjeta abre esa página (`ver_en_tienda` solo acepta esos dominios).
- **Sin juegos +18 por contenido sexual** (regla del dueño, 07/11/2026): `catalogos.py` saca los que GOG marca `nsfw`/`hentai` y los que Steam marca con avisos de contenido 3 o 4 (se pregunta solo por los que SteamSpy etiqueta como dudosos; respuestas guardadas en `docs/catalogo/steam_adultos.json`). Marcado en una tienda = se va de todas. No toca la biblioteca de cada usuario: lo que compró sigue apareciendo.
- **Precios** (`tandemstacks/precios.py`): solo de la página de 24 que se ve, en el país de Windows (`GetUserDefaultGeoName`). Steam: `IStoreBrowseService/GetItems` (ya viene escrito en la moneda local); GOG: `api.gog.com/products/prices?ids=`; Xbox: `displaycatalog` con `market` (sin precio = Game Pass). 6 h en memoria; la página los olvida al plegar No comprados.
- **Interruptor Descuento** en No comprados: al prenderlo, `precios.ofertas()` baja los ids en oferta de GOG (`catalog.gog.com` con `discounted=eq:true`, ~3000) de Steam (búsqueda pública con `specials=1`, las 4000 más relevantes) y de itch.io (`on-sale.xml`). Las demás tiendas no publican sus ofertas. Con tiendas marcadas, solo cuentan sus ofertas y la tarjeta muestra solo esas tiendas. 6 h en memoria; se sueltan al plegar.
- `Api.catalogo(tienda)` lo baja de la landing (caché 1 día) y `Api.ver_en_tienda` abre `goggalaxy://openGameView/<id>` (Galaxy dice Comprar o Instalar) o la web de GOG.
- No instalados y No comprados arrancan plegados y se dibujan al abrirlos, de a 24 (se puede elegir 48 o 96), en grilla o en lista (`VISTA`, `POR`, guardados en `localStorage` del visor), con tarjetas "Página anterior" y "Siguiente página" y abajo el número de página (`paginado()`). Cada grupo tiene su propio buscador por nombre, adentro (`BUSCA`). El catálogo se baja recién al desplegar No comprados; portadas con `loading=lazy` (son links, no ocupan disco).
- Ubisoft: no hay catálogo usable sin claves internas de la tienda (no usarlas). Próximas candidatas con catálogo público: Steam, Xbox.

## Armar y publicar

- Requisitos: Python 3.12, `pip install -r requirements.txt pyinstaller`, Inno Setup 6 (`%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe` o Program Files (x86)).
- `.\build.ps1` → `dist\TandemStacks\TandemStacks.exe` y `installer\Output\TandemStacks-Setup-<versión>.exe` (~16 MB). PyInstaller loguea por stderr: el script no usa `$ErrorActionPreference = "Stop"` a propósito.
- Versión: solo en `tandemstacks/__init__.py` (`VERSION`); build.ps1 y el .iss la leen de ahí.
- Publicar: `git tag vX.Y.Z && git push origin vX.Y.Z && gh release create vX.Y.Z installer\Output\TandemStacks-Setup-X.Y.Z.exe --title "TandemStacks X.Y.Z" --notes "..."`. La app compara `tag_name` (sin la v) con `VERSION`.
- El instalador no está firmado: SmartScreen avisa la primera vez. **En trámite la firma gratis de SignPath Foundation** (08/11/2026): `.github/workflows/armar.yml` ya arma el instalador en GitHub (requisito de SignPath; a mano o al etiquetar `v*`, deja el instalador sin firmar como artefacto). Falta: 2FA en GitHub, mandar la solicitud (respuestas en `privado/signpath-solicitud.md`) y, si aprueban, publicar la sección "Code signing policy" y sumar los pasos de firma al workflow.

## Decisiones tomadas (no volver a discutir)

- **La app consume lo menos posible (regla del dueño, 07/11/2026).** Portadas en su versión chica (`chica()` en la plantilla: Epic `?w=360`, Xbox `?w=300`, GOG `_glx_vertical_cover.webp`), tarjetas fuera de pantalla sin dibujar (`content-visibility`), visor con caché de 64 MB y sin servicios de Edge en segundo plano (`WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS` en `main()`). Nada se carga hasta que se usa y lo que se deja de ver se suelta de la memoria: los grupos se dibujan al desplegarlos y se sueltan al plegarlos; el catálogo se lee al desplegar No comprados y se libera al plegarlo; minimizada, el visor baja su memoria y se suspende (`_minimizada` en `app.py`). Toda función nueva sigue este criterio. **Al cerrar cualquier ventana vuelve a su origen** (10/11/2026): la ficha restaura la tarjeta como estaba (`g._antes`) y las ventanas se vacían. Revisión de consumo del 10/11/2026: la huella de cada 12 s no copia las bases si no cambiaron (`stores._huellas`), lee solo nombres de subclaves (`_subclaves`) y relee "Programas instalados" solo si cambió su fecha (`_escrita`); Steam relee un appmanifest solo si cambió (`steam._manif`) y la huella ya no usa el tamaño (no reescanea durante una actualización); `watch._procs` pide la ruta de cada proceso una sola vez; durante las fichas no se escribe `biblioteca.html` y la página se avisa cada 30 s; `tamanos.json` se guarda una vez por escaneo y olvida lo desinstalado; portadas que no existen se anotan (`sin:<id>`, una semana); nivel y descargas no se redibujan si no cambiaron; al arrancar un juego la ventana se minimiza y se duerme; al abrir se borran fichas de más de 30 días (`_podar_cache`). La fase 2 del escaneo solo baja fichas de los instalados; las demás se bajan al abrirlas (`fichas.de`) y no se guardan en `NUC.juegos`.

- **Regla principal: la app funciona 100 % sin IA.** Es una aplicación normal: nada de llamadas a modelos de IA (Claude, OpenAI, etc.) ni funciones que dependan de una. Todo sale de archivos locales, el registro de Windows y APIs públicas de las tiendas. Claude solo se usa para programarla.

- Bibliotecas **automáticas sin logins**: Steam completa solo con clave Web API del usuario (se pide en Configuración, link a steamcommunity.com/dev/apikey); **Epic completa desde `C:\ProgramData\Epic\EpicGamesLauncher\Data\Catalog\catcache.bin`** (base64 de JSON que guarda el launcher; base = `mainGameItem.id` vacío, se filtran extras por nombre con `EPIC_NO_JUEGO`; portada `DieselGameBoxTall`; la URI `com.epicgames.launcher://apps/ns%3Aitem%3Aapp?action=launch` instala o juega); Riot y Battle.net = catálogo gratis + instalados; EA/Xbox/Ubisoft = solo instalados; Rockstar = manifiestos. Se descartó integrar logins de Epic/EA (frágil, mucho trabajo).
- Formato: instalador .exe (no portable). Publicación: GitHub público con releases y aviso de versión nueva.
- **Ubisoft = instalados + los reconocidos por ícono** (01/11/2026): `%LOCALAPPDATA%\Ubisoft Game Launcher\cache\ownership\*.vdat` y `configurations.vdat` están cifrados; no leer tokens de `ConnectSecureStorage.dat`. La caché web del launcher solo tiene el catálogo de Ubisoft+ (`ownership: 0`), no la cuenta. La app lo explica en la tarjeta de Ubisoft.
- `steamcommunity.com/profiles/<id>/games?xml=1` ya no sirve para leer la biblioteca: no insistir.
- Epic GraphQL (`store.epicgames.com/graphql`) está detrás de Cloudflare: no sirve desde Python; usar el endpoint de contenido por slug.
